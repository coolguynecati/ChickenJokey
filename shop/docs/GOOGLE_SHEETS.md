# Google Таблица — журнал заказов Дымного двора

Сервер дописывает строки при каждом событии. Из CRM таблицу **нельзя** стереть или подправить — пишет только служебный аккаунт Google.

## Что попадает в таблицу

| Колонка | Содержание |
|--------|------------|
| Время (МСК) | когда случилось событие |
| Событие | ЗАКАЗ СОЗДАН / НАЧАЛИ ГОТОВИТЬ / ОТДАН КУРЬЕРУ / В АРХИВ / УДАЛЁН … |
| № заказа | например DD2026-0001 |
| Имя, телефон, состав, сумма | снимок на момент события |
| Кто (кабинет) | «сайт» или название кабинета CRM (сейчас общий пароль = «Дымный Двор») |

## Настройка (один раз)

### 1. Создайте таблицу
В Google Drive → Новая Google Таблица.  
Переименуйте лист в **`Журнал заказов`** (или запомните другое имя).  
Скопируйте **ID** из URL:  
`https://docs.google.com/spreadsheets/d/←ВОТ_ЭТОТ_ID→/edit`

### 2. Service Account в Google Cloud
1. [console.cloud.google.com](https://console.cloud.google.com/) → создайте проект (или выберите).
2. **APIs & Services → Enable APIs** → включите **Google Sheets API**.
3. **IAM & Admin → Service Accounts → Create**.
4. Создайте ключ **JSON** и скачайте файл.

### 3. Доступ к таблице
Откройте таблицу → **Настройки доступа** → добавьте **email** из JSON (`client_email`, вида `...@....iam.gserviceaccount.com`) с правом **Редактор**.

### 4. Переменные на Render
В сервисе `chickenjokey` → Environment:

```
GOOGLE_SHEETS_ID=ваш_id_таблицы
GOOGLE_SHEETS_TAB=Журнал заказов
GOOGLE_SHEETS_BRANDS=dymny-dvor
GOOGLE_SERVICE_ACCOUNT_JSON=<весь JSON одной строкой>
```

Либо вместо JSON:

```
GOOGLE_SERVICE_ACCOUNT_EMAIL=...@....iam.gserviceaccount.com
GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

В `PRIVATE_KEY` сохраните переносы как `\n`.

### 5. Проверка
После деплоя: `GET https://chickenjokey.onrender.com/api/health`  
Должно быть `"sheetsAudit": true`.

Сделайте тестовый заказ на сайте — в таблице появится строка **ЗАКАЗ СОЗДАН**.  
Смените статус в CRM — появится новая строка (история не затирается).

## Важно
- Доступ к таблице давайте только себе (`narek@` / `info@`), **не** менеджерам кухни.
- Пока один пароль CRM — в колонке «Кто» будет кабинет, не ФИО человека. Личные логины можно добавить позже.
- `GOOGLE_SHEETS_BRANDS=*` — писать все бренды; по умолчанию только Дымный двор.
